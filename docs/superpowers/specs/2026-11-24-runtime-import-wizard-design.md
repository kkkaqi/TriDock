# 本地运行环境导入向导

用户确认继续完善：选择系统、下载说明、本地文件或目录识别、兼容性与电脑条件检查、创建实例、试启动。继续保持零预装镜像、零自动镜像下载，不改动外部游戏项目。

向导分为“选择平台与来源”“检查环境”“创建并试启动”。平台目录明确列出当前适配器与导入格式，不把未实测版本称为已验证。支持本地完整运行环境目录及 ZIP 压缩包；ZIP 先检查内容与展开大小，用户选择存放目录后才解压，不覆盖现有文件。单独 IMG、ISO、IPSW 给出对应准备说明。

独立 runtime_inspector.py 读取目录和配置，自动查找常见单层/两层解压目录、Android 已有 AVD、SDK 工具、Oniro 内核架构、ASoftware 内核和系统盘。检查不执行导入包内的脚本、不启动系统、不下载文件。Android 选择已有设备；尚未创建的设备明确引导到 Android Studio，避免伪造 AVD 配置。

检查结果包含识别的平台/架构、可确认的版本、文件缺失、宿主内存/CPU/虚拟化信息、磁盘可用量与实例数据空间预估。未知值显示未知。自动识别不足时保留手动选择 hdc 和 iOS 数据目录。检查完成后才创建实例；创建与启动时后端重新校验，防止界面过期或绕过检查。

ZIP 校验拒绝路径越界、盘符、符号链接、重复文件、加密包、异常压缩率与过多文件；流式解压到用户选择的空目录，按展开大小检查磁盘空间，失败只清理本次创建的临时目录。镜像目录保持引用，Oniro 的可写分区工作副本由其后端创建。

“试启动”单独显示文件检查通过、进程运行、设备就绪三种状态。Android 使用目标 adb 的 boot_completed；OpenHarmony 使用目标 hdc；iOS 仅能确认进程状态，明确提示在系统窗口确认引导，不伪报就绪。

测试覆盖识别、架构/缺失/磁盘校验、只读检查、ZIP 边界与解压、过期检查、设备目标以及原有实例兼容；Electron 测试完整检查后创建和失效反馈。使用临时合成环境进行自动化，不下载真实镜像。更新安装包并核验资源中无镜像。
